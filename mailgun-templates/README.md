# Mailgun Templates

Diese HTML-Dateien kannst du jeweils in den Mailgun HTML Editor kopieren.

- `hypnose-termin-bestaetigungslink.html` -> `hypnose termin bestaetigungslink`
- `me-hypnose-termin-reserviert.html` -> `me - hypnose termin reserviert`
- `hypnose-termin-bestaetigt.html` -> `hypnose termin bestaetigt`
- `me-hypnose-termin-bestaetigt.html` -> `me - hypnose termin bestaetigt`
- `hypnose-termin-storniert.html` -> `hypnose termin storniert`
- `me-hypnose-termin-storniert.html` -> `me - hypnose termin storniert`

Wichtige Variablen:

- `{{name}}`
- `{{email}}`
- `{{phone}}`
- `{{service}}`
- `{{appointmentDate}}`
- `{{appointmentEnd}}`
- `{{address}}`
- `{{priceLabel}}`
- `{{paymentMethods}}`
- `{{confirmUrl}}`
- `{{cancelUrl}}`
- `{{note}}`
- `{{token}}`
